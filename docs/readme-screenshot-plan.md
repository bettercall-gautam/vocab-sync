# README Screenshot Plan

The public README will use screenshots from the unconnected Vocab Sync state so no personal Google Drive content, API keys, account details, or vocabulary history is exposed.

| Asset | Viewport | Content shown | Documentation purpose |
| --- | --- | --- | --- |
| Desktop capture | 1440 × 900 | Smart capture workspace, Drive destination card, safe sync card, and the three visible capture choices. | Establishes the primary desktop workflow and visual identity. |
| Mobile capture | 375 × 812 | Compact top navigation, Connect Drive action, and Smart capture workspace. | Demonstrates that the same workflow is usable on a phone. |
| Review workspace | Desktop preview | Five-word daily recall workspace in the empty, no-private-data state. | Shows the separate recall flow and plain-language learning focus. |
| Library workspace | Desktop preview | Library heading plus Markdown, CSV, and Change file controls in the empty, no-private-data state. | Shows the searchable collection and export workflow without exposing vocabulary entries. |

All captures show the current UI accurately and contain only placeholder examples or an unconnected empty state. The final collage will be stored in `docs/images/` so GitHub renders it directly in the README.
